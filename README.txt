학교 알리미 0.1.22 (Windows x64)

실행 방법
0. 새 EXE를 실행하면 이전 설치 버전을 정상 종료하고 새 버전으로 교체합니다.
   업데이트 전 SQLite 온라인 백업을 만들며 미완료 일정을 완료 처리하지 않습니다.
   정상 종료가 거부되면 이유를 표시하고 업데이트를 중단합니다.
1. SchoolAlimi.exe를 실행합니다. Python 또는 별도 런타임 설치가 필요 없습니다.
2. 첫 실행 시 현재 Windows 계정의 로컬 앱 폴더에 실행 파일을 복사합니다.
   이후 로그인하면 트레이에서 자동 실행합니다. 설정에서 자동 시작을 끌 수 있습니다.
3. 상단 '포스트잇 동작 확인'을 누르면 오늘 테스트 메모를 즉시 표시합니다.
   제목을 누르면 세부 내용과 완료 버튼이 나타납니다. 기존 학교 일정의 날짜와 상태는 바뀌지 않습니다.
4. 관리 창을 닫아도 바탕화면 일정 메모장, 알림 메모와 트레이는 유지됩니다.
   일정 메모장은 시작할 때 글자와 배경 없이 작은 메모장 아이콘만 표시합니다.
   메모장 아이콘과 펼친 메모장은 항상 다른 일반 프로그램 창 위에 표시합니다.
   아이콘에는 닫기 버튼이 없습니다. 아이콘을 오른쪽 클릭한 뒤 '닫기'를 선택하세요.
   아이콘을 더블클릭하면 입력할 수 있는 메모장이 펼쳐집니다.
   펼친 메모장의 상단 제목 영역을 더블클릭하거나 최소화 버튼을 누르면 다시 아이콘이 됩니다.
   입력칸 더블클릭은 단어를 선택합니다. 아이콘 상태에서도 파일을 드롭하거나 Ctrl+V로 붙여넣을 수 있습니다.
   접어도 초안·커서·실행 취소를 유지하며, 주기적인 일정 갱신은 펼친/접힌 상태를 바꾸지 않습니다.
   화면 가장자리에서 펼칠 때는 입력창을 화면 안으로 옮기고, 접으면 원래 아이콘 위치로 돌아갑니다.
   메모장 입력칸을 클릭해 Ctrl+V로 붙여넣거나 파일·이미지·텍스트를 끌어 놓으세요.
   '붙여넣기' 버튼도 사용할 수 있습니다. 인식한 일정을 팝업으로 표시합니다.
   제목·날짜/월·시간·장소·세부 내용을 수정하고 '등록'을 눌러야 최종 저장됩니다.
   확인 창의 '인식한 텍스트' 탭에서 안내문 등 일정 외의 전체 본문도 수정할 수 있습니다.
   이 탭을 수정해도 위 표의 일정 제목·날짜·시간은 바뀌지 않습니다.
   수정한 텍스트는 관리 창 입력칸에 반영되며 PC에 자동 저장됩니다.
   다른 내용이 담긴 메모장 초안은 덮어쓰지 않고 유지합니다.
   일정을 등록하지 않거나 인식된 일정이 없어도 수정한 초안은 남습니다.
   수정한 텍스트로 일정을 다시 찾으려면 관리 창에서 '일정 찾고 확인'을 누르세요.
   '일정 원문 (참고)' 탭에는 선택한 일정의 인식 당시 원문을 그대로 보관합니다.
   직접 타이핑한 내용은 '일정 확인' 또는 Ctrl+Enter로 분석합니다.
   취소하면 저장하지 않습니다. 메모장 초안은 PC에 저장되어 다시 실행해도 남습니다.
5. 상단 '바탕화면 보기'에서 포스트잇 또는 목록을 선택하세요.
   포스트잇은 제목 왼쪽에 마감 날짜와 요일을 표시합니다. 예: 10/15(목).
   기간 일정은 마지막 날을 마감 날짜로 사용하며, 달만 있는 일정은 10월처럼 월만 표시합니다.
   처음에는 날짜 제한 없이 모든 확정된 미완료 일정을 표시합니다. 색상은 마감 3일 전·2일 전·1일 전 순서로
   노란색이 점점 진해지고, 당일과 지난 미완료 일정은 주황색을 유지합니다.
   목록 모드도 같은 기준으로 행 색을 바꿉니다. 날짜가 지나면 앱이 자동으로 색을 갱신합니다.
   월만 있는 일정은 특정 날짜를 만들지 않고 기본 노란색을 유지합니다.
   제목을 누르면 세부 내용을 펼치고 다시 누르면 접습니다.
   펼친 포스트잇은 다른 창과 포스트잇 앞에 표시하며 접으면 다시 바탕화면 쪽으로 돌아갑니다.
   목록도 각 항목 왼쪽에 마감 날짜·요일을 별도 열로 표시하고 오른쪽에 제목을 표시합니다.
   기간 일정은 마지막 날을, 월 일정은 '10월'처럼 월만 표시하며 날짜가 없으면 '날짜 미정'으로 표시합니다.
   날짜나 제목을 클릭하면 진한 구분선 아래에 세부 내용과 완료 버튼이 나옵니다.
6. 관리 창 상단 또는 설정의 정렬 메뉴에서 하단·상단·우측·좌측 정렬을 선택하세요.
   선택 즉시 적용하며 다음 실행에도 유지합니다. 포스트잇과 목록에 모두 적용됩니다.
   점 모양 이동 영역을 잡아 옮기면 자유 배치로 바뀝니다.
   '정렬 적용'을 누르면 마지막으로 선택한 정렬 방향으로 다시 모읍니다.
   접힌 알림은 다른 프로그램 창 아래에 표시됩니다. 관리창은 닫아도 바탕화면 알림이 남습니다.
7. 관리 창, 포스트잇, 일정 목록, 펼친 메모장에는 닫기 버튼이 있습니다.
   접힌 메모장 아이콘은 오른쪽 클릭 메뉴의 '닫기'로 닫을 수 있습니다.
   닫기를 누르면 경고 확인창을 표시하며, 취소하면 창을 그대로 유지합니다.
   확인하면 해당 도구만 닫고 일정은 미완료 상태로 보존하며 메모장 초안도 저장합니다.
   닫은 도구는 일정 갱신 때 다시 나타나지 않습니다. 다음 실행에는 다시 표시됩니다.
   트레이의 '달력 열기', '일정 메모장 열기', '바탕화면 알림 다시 열기'로 다시 열 수 있습니다.
   트레이의 '알리미 종료'는 미완료 일정이 있어도 프로그램을 종료합니다.
   미완료 일정은 로컬 DB에 그대로 보존되며 다음 실행 때 저장한 표시 설정에 따라 다시 불러옵니다.
   종료 직전에 입력한 메모장 초안도 로컬에 저장합니다.
   화면 캡처 도구의 닫기와 일정 입력·등록 확인창의 X도 닫기 전에 확인합니다.
   세부 내용의 완료 버튼을 누르면 일정 제목·날짜를 확인하는 팝업이 표시됩니다.
   팝업의 '완료'를 눌러야 완료 처리합니다. 기본 선택은 취소이며 Esc·X도 취소합니다.
   취소하면 일정과 상세 화면을 그대로 유지합니다. 포스트잇과 목록에 모두 적용됩니다.
   완료 기록에서 완료 취소하면 해당 메모가 복원됩니다.
8. 설정의 '바탕화면에 표시할 미완료 일정'에서 표시 기간을 정할 수 있습니다.
   '날짜 제한 없이 모든 미완료 일정 표시'를 체크하면 과거·미래 일정을 모두 표시합니다.
   체크를 해제하면 오늘 기준으로 며칠 전부터 며칠 후까지 표시할지 각각 입력합니다.
   제한 모드의 기본값은 30일 전부터 14일 후까지이며, 0일로 설정하면 해당 방향은 오늘까지만 표시합니다.
   기간 일정은 종료일을 마감 날짜로, 월 일정은 해당 월 전체와 표시 기간의 겹침으로 판단합니다.
   설정은 즉시 적용하고 재실행 후에도 유지됩니다. 숨겨진 일정은 삭제하거나 완료 처리하지 않습니다.
   이미 저장된 일정을 다시 등록하면 중복을 만들지 않으며, 완료된 기존 일정의 상태도 유지합니다.
   확인 창에는 기존에 저장한 내용이 표시되며, 제목·날짜·시간·장소·세부 내용을 수정한 뒤
   등록하면 새 일정을 만들지 않고 해당 기존 일정에 반영합니다. 수정하지 않은 중복은 유지합니다.
9. 관리 창에서 기존 일정을 수정해 확정 저장하면 수정한 일정을 바로 선택하고 저장 결과를 표시합니다.
   날짜를 다른 날로 옮기면 달력도 해당 날짜로 이동합니다.
   완료 기록에서 날짜 수정으로 순서가 바뀌어도 같은 일정을 선택한 상태로 유지합니다.
   확인 필요 일정이 확정되어 목록에서 빠지면 다른 일정으로 선택이 넘어가지 않습니다.
10. 설정의 '일정 초기화'에서 시작일·종료일을 지정하고 '지정 기간 일정 초기화'를 누르세요.
    선택 기간과 하루 이상 겹치는 일정과 해당 월의 월 일정을 삭제합니다. 양 끝 날짜도 포함합니다.
    완료·확인 필요 일정도 포함하며, 날짜 없는 일정은 '전체 일정 초기화'에서만 삭제합니다.
    '전체 일정 초기화'는 모든 날짜의 일정과 완료 기록·확인 필요 일정을 삭제합니다.
    확인창에서 대상 건수를 확인한 뒤 실행합니다. 기본 선택은 취소입니다.
    삭제 직전에 자동 백업을 만들며 백업에 실패하면 삭제하지 않습니다.
    설정·자동 시작·메모장 초안·인식한 텍스트 초안은 유지합니다.
    초기화 결과에 표시된 백업을 '백업 파일에서 복원'으로 불러오면 초기화 전 상태로 복원합니다.
11. Windows 로그인으로 시작해도 저장한 표시 기간에 해당하는 미완료 일정을 다시 표시합니다.
    시작 직후에는 바탕화면 준비 상태를 따라 표시 위치와 창 순서를 여러 번 갱신합니다.
    일정을 먼저 표시한 뒤 일일 자동 백업을 실행하며, 백업 실패가 일정 표시를 중단하지 않습니다.
    자동 백업 실패 시 저장 공간·데이터 폴더를 확인하세요. 백업은 1분 뒤 다시 시도합니다.

지원 기능
- 달력, 직접 일정 추가·수정, 지난 미완료 일정 복구
- 독립 포스트잇·목록 모드, 제목 클릭 상세 보기, 펼친 포스트잇 앞에 표시, 마감 날짜·요일 표시
- 각 도구의 닫기 버튼·경고 확인창, 일정과 초안 보존, 트레이에서 닫은 도구 다시 열기
- 포스트잇·목록의 완료 확인 팝업, 기본 취소·Esc·X 취소, 확인 후 완료 기록 저장
- 하단·상단·우측·좌측 정렬, 위치·보기 모드·정렬 방향 저장
- 오늘 기준 전후 표시 일수 설정·기간 제한 없음, 단계별 마감 색상, 당일·기한 지난 일정 주황색 표시
- 텍스트 붙여넣기, 클립보드 이미지, 화면 영역 캡처, 파일 가져오기
- 바탕화면 일정 메모장에 텍스트·복사한 파일·이미지 붙여넣기 및 드래그
- 배경·글자 없는 바탕화면 메모장 아이콘, 항상 다른 창 위에 표시, 더블클릭으로 펼치기·접기, 최소화 버튼, 아이콘 위치 저장
- PDF 등 문서는 파일을 끌어 놓거나 '파일에서 일정 가져오기'에서 선택하면 확인 팝업을 엽니다.
- '일정 찾고 확인'에서 입력칸이 비어 있으면 파일 선택 창을 엽니다.
- 확인 팝업에서 수정, 행 추가·삭제, 포함 선택 후 등록하며 취소 시 일정은 저장되지 않습니다.
- 여러 파일은 한 팝업으로 모아 보여주며 읽지 못한 파일의 이유도 표시합니다.
- 파일·이미지에서 읽은 원문을 입력칸에도 표시하며 다시 등록해도 중복은 만들지 않습니다.
- 오프라인 한국어 OCR, 날짜·시간·장소 추출 및 중복 방지
- 월별 달력 아래에 날짜·행사가 나열된 학사일정표 이미지를 월별로 나누어 읽습니다.
  연도·월 제목과 '1(월)', '12(월)~16(금)' 등의 항목을 연결하고 달력 숫자·수업일수는 제외합니다.
  '7.21~8.18 여름방학'은 시작일·종료일을 가진 일정 하나로 표시합니다.
  문서에 적힌 연도를 유지하며, 연도가 없거나 날짜·요일이 맞지 않으면 확인이 필요하다고 표시합니다.
  작은 글자의 OCR 오타는 확인창에서 수정한 뒤 등록하세요. 선명한 원본 이미지가 더 정확합니다.
- '2026.10.22.(목),15:00-19:00'처럼 날짜 뒤에 시간 범위가 있는 문장은 일정 하나로 인식합니다.
  시작 시간은 시간 칸에 표시하고 전체 시간 범위는 원문과 제목에 유지합니다.
- 포스트잇·목록·달력·확인 창·완료 기록에는 별도의 출처 표시를 하지 않습니다.
- 날짜를 추출해도 문장에 포함된 날짜 표현은 제목에 유지합니다.
  예: '10월 30일까지 수행평가 제출하세요'를 그대로 표시하며 마감 날짜도 따로 저장합니다.
  기존 일정도 원문과 이전 자동 제목이 정확하게 일치하면 날짜 표현을 복원합니다. 직접 수정한 제목은 유지합니다.
- 월만 적힌 일정은 날짜를 만들어 표시하지 않고 9월, 10월처럼 표시합니다.
- 월 일정의 표시 여부도 설정한 기간에 따르며, 날짜를 만들어 표시하지 않습니다.
- 기존에 가져온 월 일정도 원문을 확인해 월 표시로 자동 변환합니다. 실제 1일 일정은 날짜를 유지합니다.
- 직접 입력에서 YYYY-MM은 월 일정, YYYY-MM-DD는 날짜 일정으로 저장됩니다.
- 월 일정은 그 달 모든 날짜의 일정 목록에 표시됩니다.
- 평가 예고안의 교과·단원·평가내용·평가시기 표를 행별로 읽어 등록
- 월 표기는 확인 팝업에 YYYY-MM으로 표시하며 여러 달은 각 월별로 나눔
- 문서의 학년도·연도가 있으면 그 연도를 사용하고, 없으면 현재 연도를 사용
- TXT/CSV/TSV/MD, DOCX, XLSX, PDF, HWPX, 일반 HWP 5, PNG/JPG 등
- 불명확 날짜는 확인 팝업에서 수정하거나 포함을 해제한 뒤 등록
- 로컬 SQLite 저장, 하루 첫 실행 시 자동 백업, 백업 저장 및 복원
- 기간 지정·전체 일정 초기화, 삭제 건수 확인·자동 백업, 초안과 설정 보존
- Windows 로그인 시 일정 재표시, 자동 백업 오류와 일정 표시 분리

데이터 위치
%LOCALAPPDATA%\SchoolAlimi\
DB: alimi.sqlite3 / 자동백업: backups\ / 실행파일: bin\버전\SchoolAlimi.exe
자료와 일정은 외부로 전송하지 않습니다. 원문 텍스트는 일정과 함께 저장됩니다.
원본 문서 자체를 복사하거나 변경하지 않습니다. SQLite 파일은 암호화되지 않습니다.

지원 범위
- 포스트잇은 확정된 미완료 일정 중 설정한 기간에 해당하는 일정만 표시합니다.
  기간 제한 없음 상태에서는 최종 등록한 즉시 표시합니다.
  기간 제한 상태에서 제외된 일정은 등록 결과에 숨겨진 이유와 설정 방법을 표시합니다.
  '확인 필요' 상태는 원문과 날짜를 확인하고 확정 저장해야 합니다.
  마감 3일 전부터 시작하는 색상 변화와 바탕화면 표시 기간은 별도로 작동합니다.
  날짜 일정의 색상은 실제 마감일, 기간 일정의 색상은 종료일을 기준으로 합니다.
  달력에서 날짜를 선택하는 것은 알림 날짜를 바꾸지 않습니다.
- Windows x64에서 실행합니다.
- 복잡한 공문·표·오래된 문서의 날짜는 확인이 필요할 수 있습니다.
- 암호 또는 배포용 HWP, 암호화 PDF는 보호를 해제하거나 HWPX/PDF로 저장 후 가져오세요.
- 화면 캡처는 현재 마우스가 있는 모니터의 선택 영역을 읽습니다.
- 접힌 포스트잇·목록은 바탕화면 위, 일반 프로그램 창 아래에 표시합니다.
  메모장 아이콘·입력창과 펼친 포스트잇은 다른 일반 프로그램 창 위에 표시합니다.
  잠금/보안 화면/강제 종료 중에는 표시할 수 없습니다.
- 관리창은 트레이로 숨겨집니다. 트레이에서 종료해도 미완료 일정과 메모장 초안은 로컬에 남습니다.
  진행 중인 자료 분석은 끝난 뒤 종료할 수 있습니다.
- 이 파일은 전자서명이 없는 초기 배포판입니다.

삭제
설정에서 자동 시작을 끄고 트레이에서 알리미를 종료하세요. 미완료 일정은 완료 처리하지 않아도 됩니다.
실행 파일을 삭제하면 앱을 제거할 수 있습니다. 위 데이터 폴더는 일정 보존을 위해 남습니다.
